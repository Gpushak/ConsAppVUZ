# Запись на консультацию к преподавателю

Сайт одной кафедры: студент записывается на групповой слот, преподаватель публикует окна, администратор заводит преподавателей и блокирует учётные записи. Слот очный (корпус и аудитория, ссылка необязательна) или онлайн (ссылка `http` или `https`, без корпуса и аудитории). Страницы отдаёт Laravel, данные и сессии лежат в MySQL. Почта, SMS, SSO и загрузка файлов не используются.

Нужны PHP 8.3+ и MySQL 8. Docker Compose ниже только для локального запуска: само приложение — обычный каталог Laravel и работает с MySQL без контейнеров.

## Запуск без Docker

```bash
composer install
cp .env.example .env
php artisan key:generate
```

Создайте базу и пользователя, как в `.env.example` (`consapp` / `secret`), затем:

```bash
php artisan migrate --seed
php artisan serve
```

Сайт откроется на http://localhost:8000. Корень сайта при выкладке на сервер — каталог `public`.

Для тестов нужна отдельная база `consapp_testing` с тем же пользователем:

```bash
php artisan test
```

## Запуск через Docker Compose

```bash
docker compose up --build
```

Приложение: http://localhost:8000. MySQL внутри сети Compose, с хоста порт 3306.
