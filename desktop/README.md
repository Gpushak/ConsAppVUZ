# Окно записи на консультацию

Отдельное окно Electron поверх уже запущенного Laravel. Свои базы, значка в трее и системных уведомлений нет: логин, роли, слоты и записи те же, что у сайта.

Дипломный сайт в обычном браузере не переключается на это окно.

## Запуск

В каталоге проекта поднимите сайт, как в корневом README:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Сайт слушает http://127.0.0.1:8000. Затем окно:

```bash
cd desktop
npm install
npm start
```

Другой адрес Laravel: `CONSAPP_URL=http://127.0.0.1:8000 npm start`.

## Меню

- **Файл** — Выйти.
- **Запись** — Записаться, Новый слот или Новый преподаватель, по роли. Клавиша Ctrl+N.
- **Вид** — Предыдущая неделя и Следующая неделя. Клавиши Ctrl+Left и Ctrl+Right.
- **Окно** — Список записавшихся, отдельным окном.

Esc закрывает диалог.
